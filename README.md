# 灵枢 LinkPivot

面向运维人员的网络拓扑管理桌面工具（Windows）。

一个工具内：**看清网络**（可视化拓扑整理）、**控住设备**（SSH/Telnet/Web/RDP 四通道安全连接）、**借助 AI**（可控的运维助手）。

> 📦 本仓库是灵枢的**安装包分发站**（不含源码）。到 [Releases](../../releases) 下载安装包。
> 🧩 AI 扩展包（防火墙设备 MCP 工具集）见姊妹仓 [linkpivot-mcp](https://github.com/HaoNan-0331/linkpivot-mcp)。

## 核心能力

**拓扑管理**
- 三栏工作区：拓扑画布 / 设备列表 / 设备详情全参数编辑
- 连线接口级编辑，未知设备一键纳管
- 导入导出拓扑数据

**设备操控**
- 单台设备按通道配置凭证：SSH / Telnet / Web / RDP 四类通道一键连接
- 凭证 AES-256-GCM 字段级加密存储，Windows DPAPI 保护主密钥
- 批量巡检与定时 ARP 采集

**AI 运维助手**
- 按需检索本地运维知识库 / 经验库
- 命令白名单内连续自主执行；越权命令命中即拦截并要求人工强确认
- 命令黑名单硬底 + 全程审计日志，plan 态只读
- 通过 [.mcpb 扩展包](https://github.com/HaoNan-0331/linkpivot-mcp)接入防火墙等设备厂商 REST API（绿盟 / 山石 / 亚信 / 上元信安等，490+ 工具）

**知识库**
- PDF / Word 文档导入解析，全文检索
- 运维经验沉淀

## 安全设计

- 凭证不出本机：字段级加密 + 主密钥 DPAPI 保护，界面默认脱敏展示
- 渲染进程沙箱隔离 + IPC 鉴权网关
- 设备命令执行过三道闸：结构校验 → 黑名单硬底 → 设备白名单策略
- AI 越权动作强确认 + 完整审计日志落库
