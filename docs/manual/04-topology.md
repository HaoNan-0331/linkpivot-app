# 第 4 章 拓扑管理

## 功能概述

拓扑管理是灵枢的核心页面（登录后默认进入）：以交互画布呈现网络设备（节点）与连接关系（连线），支持手动搭建、自动发现、自动布局、批量整理、导入导出；点选节点或连线时，画布右侧会自动展开详情栏，用于查看与编辑设备资料、管理连线。画布基于 React Flow（一个支持缩放、拖拽、框选的流程图渲染库）实现。

## 界面布局

拓扑页整体分四处：

1. **画布**：占据内容区全部空间。浅色点阵网格背景；左下角是缩放控制条（放大/缩小/适配视图按钮）；右下角是小地图（MiniMap，全图缩略导航图，缩略显示节点分布与当前视野框，仅静态展示，不支持点击/拖动跳转）。
2. **画布右下角两个悬浮圆形按钮**：从右往左分别是「+」（添加设备到拓扑，主色大圆钮）和「放大镜」（拓扑自动发现，普通大圆钮，悬停显示提示「拓扑发现」）。未选拓扑时这两个按钮不显示。
3. **页题栏拓扑工具栏**（仅在拓扑页显示）：位于内容区顶部页题栏右侧，从左到右依次为：拓扑选择下拉框、新建、保存、删除、导入、整理布局、导出七个控件。
4. **右侧详情栏**：单选一台设备或单选一条连线时自动展开，显示对应详情（见「右侧详情栏」各小节）；默认收起，左缘竖把手单击可收起/展开、拖动可调宽（见 [第 3 章 界面总览](./03-ui-tour.md)）。

### 画布节点

节点是从设备抽象出的图形块，居中显示设备类型图标（路由器/交换机/防火墙/服务器/通用/Windows 主机六种图标），图标上方显示设备名称（加粗），下方显示 IP 地址（小字）。选中节点时图标外出现蓝色描边与浅色底。Windows 主机节点的图标右上角带在线状态角标（绿色实心圆点=在线、灰色实心圆点=离线、空心圆环=长期离线，悬停显示状态词，离线/长期离线附「最近在线 {相对时间}」），随 Windows 主机页的在线状态实时变化（见 [第 5 章](./05-devices.md)）。未纳管节点（画布上存在、但设备管理中尚无对应设备记录的节点，多由自动发现导入产生）在未选中时显示黄色虚线边框，名称上方带「未纳管」徽标。节点四边各有连接锚点（上/下/左/右各一对小圆点：蓝色为入端、绿色为出端）。

| 操作 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- |
| 拖动节点 | 按住节点移动 | 节点跟鼠标移动，松手落位 | 拖动中显示对齐参考线（见下）；与其它节点重叠时松手会把被压节点平滑弹开到最近空位（被拖节点位置不变） |
| 单击节点 | 点击节点 | 选中（出现选中态边框），右侧自动展开该设备的详情栏 | 单选不再出现选区浮动条；手动收起详情栏后重复点击同一台不会展开，换选其它设备/连线才重新展开 |
| 框选 | 按住 Shift 并在空白处拖出虚线框 | 框内节点与连线全部选中 | 配合选区工具条做批量操作 |
| 双击节点 | 快速双击 | **连接设备**，按通道配置走三分支（见下表） | 连接动作详见 [第 11 章 远程终端](./11-remote-terminal.md) |
| 编辑设备 | 选中单个节点后在右侧详情栏点「编辑」 | 弹出「编辑设备」全参数表单 | 与设备管理页的编辑完全一致（见「设备详情」小节） |

**双击连接三分支**（按当前已配置的可直连通道数自动判定——SSH/Telnet/Web/RDP 四类计数，Windows 主机的 command_executor 任务通道不计入）：

| 分支 | 判定条件 | 行为 |
| --- | --- | --- |
| 零通道 | 未配置任何可直连登录通道（SSH/Telnet/Web/RDP 均未配；Windows 主机仅配任务通道时同样落入本分支） | 弹出「编辑设备」表单，顶部黄色提示「该设备尚未配置登录通道：补配任一通道的凭证并保存后，即可双击连接」（仅配任务通道的 Windows 主机提示为「该主机尚未配置可直连登录通道，可补配 RDP 远程桌面」），并自动定位到最可能要配的通道页签（按设备原连接方式推断，无则 SSH 页签） |
| 单通道 | 恰好配置了一类可直连通道 | 不弹选择框，直接用该通道连接 |
| 多通道 | 配置了两类及以上可直连通道 | 弹出「连接 {设备名}」选择框：每行一个通道（标签 + 登录描述如 `user@192.0.2.1:22` 或 Web URL），命中的行尾显示「上次使用」徽标；预选规则 = 上次使用 > 默认通道 > 固定顺序（SSH/Telnet/Web/RDP）首个；点「连 接」确认并记住本次选择（记忆按设备保存，下次双击预选它），点「取 消」放弃。配了任务通道的 Windows 主机在选择框底部另有一行静态展示「command_executor @{识别码}」带「任务通道」徽标——仅展示、不可选 |

双击连接失败时按通道提示归因：「SSH 连接失败」「Telnet 连接失败」「Web 连接失败」「RDP 连接失败」（无法归因时提示「连接失败」）。

### 右侧详情栏

右侧详情栏即 [第 3 章 界面总览](./03-ui-tour.md) 介绍的详情栏，在拓扑页有两种内容形态，按画布选中状态自动切换：

| 选中状态 | 详情栏内容 |
| --- | --- |
| 恰好单选一台设备节点 | 设备详情（见下节） |
| 恰好单选一条连线 | 连线详情（见「连线详情」小节） |
| 零选中 / 多选 / 离开拓扑页 | 自动收起 |

展开与收起规则：

- 点选（含换选）设备或连线，详情栏自动展开并切换内容；
- 左缘竖把手：单击手动收起/展开，按住左右拖动调整宽度（240 像素～窗口宽度的 40%，宽度记忆保存）；
- 手动收起的意图优先：收起后重复点击同一台设备/同一条连线不会重新展开；执行「整理布局」、自动发现导入等画布操作也不会把它强制弹开；换选任意其它设备或连线才会自动重新展开。

### 设备详情（单选节点）

单选一台设备节点后，详情栏先短暂转圈加载，随后自上而下显示三区内容：

**基础信息区**：设备名（加粗标题）、在线状态（在线/离线/未知，绿/红/灰三色字）、上次检测时间（未检测过显示「未检测」），以及类型、厂商、型号、IP、固件版本五个字段行（空值显示「—」）。

**登录通道区**：固定显示四行——SSH、Telnet、Web 界面、RDP 远程桌面（登录设备的四类可直连远程通道）。已配置的行显示 ✓、「用户名:端口」描述与行内「连接」按钮（端口未单独配置时，SSH/Telnet/RDP 行按默认端口 22/23/3389 补全显示，Web 界面不补默认端口），默认通道行追加「·默认」徽标。点击「连接」直接发起该通道连接，失败提示「SSH 连接失败」等带通道名的错误。未配置的行弱化显示「✗ 未配置」。已绑定客户端的 Windows 主机在四行之下追加第五行：command_executor「✓ 已托管 · 在线/离线/长期离线」（任务通道无交互终端，不提供「连接」按钮；状态后缀悬停显示最近在线时间）。

**快捷操作区**：

| 按钮 | 行为 | 规则与限制 |
| --- | --- | --- |
| 「编辑」 | 弹出「编辑设备」全参数表单（基础字段 + 四通道凭证区 + 默认通道设置） | 与 [第 5 章 设备管理](./05-devices.md) 的编辑表单完全一致；保存成功提示「设备更新成功」，右栏与画布节点显示同步刷新；失败提示「操作失败，数据已回滚无变化：…」且弹窗不关闭 |

| 「AI 对话」 | 跳转到 AI 助手页并自动选中该设备（见 [第 7 章 AI 助手](./07-ai-assistant.md)） | — |
| 「执行命令」 | 打开「执行命令」弹窗，向该主机下发命令（与 Windows 主机页手动执行同款，见 [第 5 章](./05-devices.md)） | 仅 Windows 主机显示；主机离线时按钮禁用，悬停提示「主机离线，无法执行命令」 |
| 「从拓扑移除」 | 点击立即把该节点及其关联连线从当前画布移除（免确认） | 轻删（可随时重做的删除）：设备管理页中的设备记录原样保留，可重新添加；详情栏自动收起 |

加载除正常显示外还可能出现两种状态：

- **设备不存在或已删除**（节点引用的设备记录已不在资产表中，含未纳管节点）：显示说明文案，并提供两个动作——「一键添加到资产列表」（弹出「添加设备」表单，名称与类型已按节点预填，补齐 IP 等信息保存后节点自动关联新设备，虚线框与徽标消失，右栏切换为正常详情）与「删除节点」（点击立即从画布删除该节点，免确认；此类节点不涉及资产数据，重新发现可找回）。
- **设备信息加载失败**（查询详情时出错，设备可能实际仍存在）：仅显示错误文案与「重试」按钮，不提供纳管/删除动作，避免在状态不明时误删实际存在的设备。

### 连线

从节点边缘锚点按住拖到另一节点锚点松开即可创建连线，随后弹出「连接接口配置」窗：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 源接口（{源设备名}） | 是 | 占位提示「例: GigabitEthernet0/0/1」，留空提示「请输入源接口名称」 |
| 目标接口（{目标设备名}） | 是 | 同上 |

确认后连线生成，线中点显示接口标签（格式「源接口 — 目标接口」，任一侧有值才显示）。连线自动选择两端最近的锚点方位走直线，拖动节点时连线与标签实时跟随。单击选中连线后，右侧展开「连线详情」，可在其中修改接口标注或删除连线（见下节）；合计选中 ≥2 时也可用选区工具条批量删除。自动发现导入的连线可能缺少接口信息（此时无标签），可后续在连线详情中补填。

### 连线详情（单选连线）

单选一条连线后，详情栏显示「连线详情」，三个分区：

| 分区 | 内容与行为 |
| --- | --- |
| 链路两端 | 源端设备/目标端设备的名称。已纳管的一端显示为可点击的强调色文字，点击后画布选中自动切换到该设备节点、右栏随之切换为该设备详情；未纳管的一端为普通文本（无名称时显示「未知设备」），不可点击 |
| 接口标注 | 「源端接口」「目标端接口」两个输入框（占位提示「例: GigabitEthernet0/0/1」），输入后点击别处（失焦）即自动保存——无确认按钮，改错可重新改回；走 1 秒自动落库链，画布连线标签同步更新 |
| 操作 | 「删除连线」红色按钮，点击立即删除该连线（免确认，可重新拖线连接），详情栏自动收起 |

### 对齐参考线与防重叠

- **参考线吸附**：拖动节点时，当节点与其它节点的边缘/中心/中线接近对齐（阈值约 6 画布像素）时，节点自动吸附对齐并显示一条贯穿两者的参考线，松手落位。
- **防重叠弹开**：松手时若落点压住其它节点，被压节点自动弹开到最近空位（150 毫秒平滑滑动），拖动的节点位置保持不动；多台被压时连锁让位（有界深度）。
- 节点默认尺寸 80×60 像素；自动布局节点间距约 260 像素。

### 整理布局（自动布局）

点击页题栏工具栏「整理布局」按钮，按当前选中状态执行三种模式（自研星型分层放射算法，无第三方布局库）：

| 选中状态 | 模式 | 行为 | 按钮悬停提示 |
| --- | --- | --- | --- |
| 未选中 | 全图星型分层 | 剔除「叶子」设备（只连一条线的末端设备）后，选连接度最高的设备定在中心，其余按连接层级一圈圈向外放射排列 | 「未选中：按连接层级星型排列全图」 |
| 选中 1 台 | 定根全图 | 以该设备为中心，全图按层级放射排列 | 「已选 1 台：以该设备为中心排列全图」 |
| 选中多台 | 仅整理选中集 | 只重排选中的设备，其余不动 | 「已选多台：仅整理选中设备」 |

**布局预览态**：执行整理后不立即保存，画布顶部居中出现白色横幅：「已生成布局预览，可直接拖拽微调」+「保存布局」（主按钮）+「撤销布局」。预览期间：

- 可以继续拖拽节点微调，微调结果与布局结果在点「保存布局」时一并落库（成功提示「布局已保存」）；
- 「撤销布局」一键恢复布局前的全部位置（提示「已撤销，恢复布局前位置」，不弹确认）；
- 自动保存挂起（预览期间的改动不会偷偷落库）；此时切换拓扑会弹「布局预览尚未保存」确认框防误离开；
- 整理失败（布局算法异常）提示「布局整理失败，画布未改动」，画布保持原样；空画布时点击无任何提示（静默不处理）。

### 自动保存

拓扑的节点位置、连线等改动在停止操作约 1 秒后自动保存到数据库（无需手动点保存）；页题栏工具栏「保存」按钮用于立即保存并得到「保存成功」提示。两种方式写入相同数据。连线详情中的接口标注修改同样走此自动保存链。

### 添加设备到拓扑（画布右下角「+」）

点击后弹出「添加设备到拓扑」窗（宽约 700 像素），内嵌设备表格（列：名称 / IP地址 / 类型 / 厂商），带多选列。只列出**尚未加入当前拓扑**的设备（已加入的不再出现）。勾选一台或多台后点「添加」：

- 未勾选点添加提示「请选择至少一个设备」；
- 新节点落在**当前视野中心附近的最近不重叠空位**（批量添加时依次散开，不互相叠压）；
- 设备需先在 [第 5 章 设备管理](./05-devices.md) 中创建才会出现在此列表。

### 拓扑自动发现（画布右下角「放大镜」）

点击后弹出「拓扑自动发现」窗（宽约 600 像素），三步流程：

**第 1 步（选择设备）**：顶部说明文字「选择需要发现拓扑的设备（仅支持 SSH/Telnet 连接的设备）。系统将通过 SSH 采集设备信息，并由 AI 分析设备间的连接关系。」下方是多选下拉框，选项格式「设备名 (IP) - 厂商」，只列出配置了 SSH 或 Telnet 通道的设备。未选设备时「开始发现」按钮禁用。

**第 2 步（采集分析）**：点「开始发现」后显示转圈与进度文案「正在采集设备信息...」。后台流程：AI 先根据设备厂商决定每台设备要执行的信息采集命令（如查看邻居、接口状态的命令）→ 命令逐条经命令白名单校验（不合规的自动跳过）→ 在设备上执行并收集输出 → AI 分析输出推断设备间连接关系。此过程依赖已配置可用的 AI 模型（见 [第 10 章](./10-settings.md)）。

**第 3 步（结果确认）**：完成后显示：

- 绿色结果条「发现 N 个节点、M 条连线」；
- 「发现的节点：」列表（蓝色标签显示设备名，后跟 IP）；
- 「发现的连线：」列表（格式「设备A → 设备B (源接口 - 目标接口)」，接口缺失时省略括号）；
- 「失败的设备：」列表（红色标签设备名 + 具体错误，仅采集失败的设备出现）；
- 全部失败时显示红色「发现失败」错误块。

点「确认并导入 (N 节点, M 连线)」将结果合并进当前拓扑——已存在的节点/连线不会重复导入，导入后提示「导入 N 个节点、M 条连线」；全部已存在时提示「所有节点和连线已存在，无需导入」。点「取消」放弃。

### 画布通用操作

| 操作 | 方式 | 行为 |
| --- | --- | --- |
| 缩放 | 鼠标滚轮 / Controls 按钮 | 以指针为中心缩放 |
| 平移 | 拖动画布空白处 | 移动视野（空白处直接拖动始终是平移，不会转为框选；框选需按住 Shift 拖动（见上「框选」），点按空白即取消全部选中） |
| 取消选中 | 点击画布空白处 | 清空节点与连线选中态，选区工具条消失，右侧详情栏收起 |
| 跳转视野 | 平移/缩放/适配全图（小地图不可交互） | 快速定位到目标区域；小地图仅静态展示，点击/拖动无效果 |
| 适配全图 | 左下角 fitView 按钮 | 自动缩放平移使全部节点可见 |
| 删除选中 | 单选经右侧详情栏的删除按钮；合计 ≥2 经选区工具条「删除」 | 删除选中节点与连线（选中后按 Backspace 键也无确认直删，随自动保存落库） |

### 多拓扑管理

灵枢支持维护多份拓扑（例如「办公网」「生产网」各一份）。拓扑按最近更新排序显示在下拉框中，默认加载最近更新的一份。各拓扑的节点/连线数据独立保存；同一台设备可以出现在多份拓扑中（节点引用设备，不复制数据）。切换拓扑的路径：页题栏拓扑选择下拉框；新建/导入后自动切到新拓扑；删除当前拓扑后自动切到列表中下一份（无拓扑时画布清空）。

### 小地图与视图

- 小地图位于画布右下角：缩略显示全部节点位置与当前视野范围，仅静态展示，不支持点击/拖动跳转视野。
- 左下角 Controls 工具条：放大、缩小、适配全图（fitView）按钮。
- 打开拓扑时自动适配全图显示。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| 自动保存 | 停止操作约 1 秒后自动落库；布局预览期间挂起 |
| 页面切换 | 离开拓扑页再回来，画布视图复位（自动适配全图），节点与连线数据不丢 |
| 导入文件格式 | 仅 .json；内容须为灵枢导出的拓扑 JSON 结构；单文件节点上限 5000（超出提示「节点数量超过上限 5000，请精简后导入」）；导入的拓扑默认名为「Imported Topology」（JSON 未携带名称时） |
| 自动发现范围 | 仅 SSH/Telnet 设备参与；命令执行受白名单约束；依赖 AI 配置 |
| 删除设备与拓扑联动 | 在设备管理页删除设备会同时从拓扑中移除对应节点（见第 5 章）；在拓扑右侧详情栏「彻底删除设备」效果相同，确认后画布节点立即移除（Windows 主机的删除确认文案与卸载链见第 5 章「Windows 主机」） |
| 节点编辑一致性 | 设备编辑统一走设备单一写路径（右侧详情栏「编辑」与双击零通道引导为同一表单），保存后设备页/拓扑画布/AI 上下文同步更新 |
| 未纳管判定 | 载图时与资产表比对判定；设备管理页删除设备或发现导入后未重新载图期间，画布上的虚线框/徽标可能滞后，点选节点时右栏仍会正确给出处理入口，下次载图修正 |
| 重名约束 | 节点改名受全局设备名唯一约束（详见第 5 章「命名全局唯一」） |

## 常见问题

**Q1：拖动节点后其它设备自己动了？**
防重叠设计：松手时被压住的设备自动弹开到最近空位。如果不希望某次排布被改动，可先「整理布局」再微调。

**Q2：双击节点没反应/弹出了表单？**
双击走三分支（按可直连通道数判定，任务通道不算）：未配可直连通道会弹设备表单引导补凭证（顶部有黄色提示）；单通道直接连；多通道弹选择框。连接失败会有带通道名前缀的错误提示。

**Q3：整理布局后不满意？**
布局进入预览态不落库，点横幅上的「撤销布局」一键恢复；或直接拖拽微调后点「保存布局」。

**Q4：自动发现要多久？为什么有的设备失败了？**
耗时取决于设备数量与网络情况（逐台登录执行命令 + AI 分析）。失败列表会给出每台的具体原因（如凭证错误、超时）；只导入成功的部分即可，失败设备修正凭证后可重新发现。

**Q5：自动发现会执行危险命令吗？**
不会。AI 决定的采集命令逐条经命令白名单校验，白名单之外的命令自动跳过不执行。

**Q6：想把拓扑给别人用怎么办？**
页题栏「导出」得到 JSON 文件，对方在自己库里「导入」即可。注意：节点携带的是导出库中的设备记录 ID——同一份数据库的备份恢复后导入，双击连接不受影响；导入到另一台机器的灵枢时，若对方库中没有对应 ID 的设备记录，节点会以未纳管样式显示（虚线边框 + 徽标），可在右侧详情栏「一键添加到资产列表」快速建立设备记录并自动关联，无需重新搭建拓扑。

**Q7：画布上有的设备是虚线框，名称上方还有「未纳管」小徽标？**
这是未纳管节点——画布上有它，但设备管理页中还没有对应的设备记录（多来自自动发现导入，或导入的拓扑引用了本机库中没有的设备 ID）。点选它后在右侧详情栏可「一键添加到资产列表」（预填名称快速建档并自动关联）或「删除节点」清掉。

## 本章术语

| 术语 | 解释 |
| --- | --- |
| 节点 | 画布上代表一台设备的图形块（图标 + 名称 + IP） |
| 连线 | 两台设备间的连接关系线，可带接口标签 |
| 锚点 | 节点四边的小圆点，拖拽锚点之间创建连线 |
| 框选 | 按住 Shift 在空白处拖出选择框批量选中节点与连线 |
| 选区工具条 | 合计选中 ≥2 时浮现在选区上方的操作按钮条（对齐/删除） |
| 右侧详情栏 | 单选设备或连线时画布右侧自动展开的详情区域，有设备详情与连线详情两种形态 |
| 设备详情 | 单选节点时右侧详情栏的内容：基础信息、登录通道、快捷操作三区 |
| 连线详情 | 单选连线时右侧详情栏的内容：链路两端、接口标注、删除连线 |
| 未纳管 | 画布节点在设备管理中无对应资产记录的状态（虚线边框 + 徽标） |
| 纳管 | 为未纳管节点补建设备记录并建立关联（「一键添加到资产列表」） |
| 在线角标 | Windows 主机节点图标右上角的在线状态圆点（在线/离线/长期离线三态，悬停显示最近在线时间） |
| 任务通道 | Windows 主机的 command_executor 通道：客户端回连的命令执行通道，无交互终端，不计入双击连接的可直连通道 |
| 轻删 | 免确认、可重做、不动资产数据的删除（从拓扑移除/删除连线/删除节点） |
| 参考线 | 拖动时节点接近对齐显示的辅助线，并自动吸附 |
| 防重叠弹开 | 松手时被压节点自动让位到最近空位的机制 |
| 整理布局 | 自动排列：全图星型 / 定根全图 / 仅选中集三种模式 |
| 布局预览态 | 整理后先预览不落库，可撤销或微调后保存的中间态 |
| 小地图 | 画布右下角的全图缩略导航图（仅静态展示，不可点击跳转） |
| 自动发现 | 登录设备采集信息并由 AI 推断连接关系，一键生成拓扑 |
| 自动保存 | 停止操作约 1 秒后改动自动写入数据库 |
| 适配视图 | 自动缩放平移使全部节点可见（fitView） |
| 拓扑 JSON | 拓扑的文件交换格式，用于导入导出 |
