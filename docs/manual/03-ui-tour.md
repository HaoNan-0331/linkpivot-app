# 第 3 章 界面总览

本章带你认识登录后的主界面骨架与全软件通用的交互约定。之后各章不再重复这些内容。

## 三栏布局

登录成功后，整个窗口从左到右分为三栏：

| 栏 | 宽度 | 内容 |
| --- | --- | --- |
| 侧边栏 | 固定 208 像素 | 顶部品牌位（灵枢 LINKPIVOT 标识）+ 导航菜单（设备管理为可展开分组，含设备列表与 Windows 主机两个子项） |
| 内容区 | 弹性占满剩余空间 | 顶部页题栏（当前页面标题 + 一句话副题；拓扑管理页的页题栏右侧挂拓扑工具栏）+ 当前模块页面 |
| 详情栏 | 默认收起；单选设备/连线时自动展开，240 像素～窗口宽度 40% 之间可调 | 设备详情或连线详情（见 [第 4 章](./04-topology.md)） |

**第 1 步：看侧边栏。**
侧边栏顶部是品牌位，显示灵枢（LinkPivot）的标识与「灵枢 / LINKPIVOT」字样（不随页面切换变化）；其下是导航菜单，从上到下依次为：拓扑管理、设备管理（可展开分组：设备列表 / Windows 主机，默认展开）、IP 管理、AI 助手、知识库、日志审计、系统设置。每项左侧带图标，当前所在页面对应的菜单项高亮显示。

预期看到：登录后「拓扑管理」处于选中高亮态，内容区显示拓扑画布，顶部页题栏显示「拓扑管理 · 网络视图与设备连接」。

**第 2 步：切换页面。**
点击任意菜单项，内容区整体切换为对应模块页面，页题栏的标题与副题随之切换。注意两点：

- 页面切换即卸载重建——离开拓扑页再回来，画布视图状态（缩放/平移）不保留（拓扑数据本身不丢失）。
- 在拓扑管理页时，页题栏右侧会多出一段拓扑工具栏（拓扑选择、新建、保存、删除、导入、整理布局、导出七个控件的入口，见 [第 4 章](./04-topology.md)）。

**第 3 步：认识右侧详情栏。**
详情栏不是常驻栏：在拓扑管理页的画布上恰好单选一台设备或单选一条连线时，它才出现在内容区右缘并自动展开，显示设备详情（资料查看、登录通道、编辑入口等）或连线详情（接口标注、删除连线等），内容随选中对象自动切换，功能细节见 [第 4 章](./04-topology.md)。零选中、多选或离开拓扑页时，详情栏自动收起。

单选设备或连线期间，内容区右缘有一条竖直的窄把手（宽 8 像素的命中区，视觉上是中间一个 12×32 像素的圆角小竖条；详情栏手动收起后把手仍在，可随时再点开）。它有两种手势：

- **单击**（按压期间基本没移动）：收起或展开详情栏，一次到位。
- **按住左右拖动**：连续调整详情栏宽度；从收起状态直接拖开也有效。

点选（含换选）设备或连线时详情栏自动展开；手动收起后，重复点击同一台设备或同一条连线不会重新展开，换选其它设备或连线才会再次自动展开——手动收起的意图优先，避免反复弹开打扰。

详情栏的宽度规则：

| 规则 | 值 |
| --- | --- |
| 最小宽度 | 240 像素 |
| 默认展开宽度 | 320 像素 |
| 最大宽度 | 窗口宽度的 40%（窗口很窄时保底 240 像素） |
| 默认状态 | 收起 |
| 记忆 | 宽度与收起状态写入本地存储，重启后保持 |
| 拖拽中 | 拖动把手时内容不闪烁、画布不重排；窗口尺寸变化时已展开宽度自动重新收敛到上限内 |

## 通用交互约定

以下是贯穿所有页面的交互风格，认识一次即可：

### 胶囊按钮

主要按钮为胶囊形态（圆角明显的圆头按钮），蓝色主按钮表示当前推荐动作；次要动作为描边或纯文字按钮。危险操作（如删除）的按钮使用红色危险样式（红色文字或描边），其中彻底删除类操作通常带二次确认；AI 助手命令审批面板的「拒绝执行」按钮是例外——平时中性色、悬停才变红（见 [第 7 章 AI 助手](./07-ai-assistant.md)）。

### 悬停显形的细滚动条

所有滚动区域使用 8 像素宽的细滚动条，平时隐藏或弱化显示，鼠标悬停到滚动区域时滚动条变清晰。列表、对话区、弹窗内滚动区均遵循此约定。

### 分页与截断提示条

大数据列表（IP 明细、OUI、异常记录、经验列表等）采用分页表格，右下角分页器显示「第 X-Y 条 / 共 Z 条」的范围式统计。当单次查询结果超出安全上限被截断时，列表上方出现黄色提示条：「已显示前 N 条 / 共 M 条」，并附带应对建议（如收紧筛选条件）。这是数据安全上限机制，不是 bug。

### 弹窗与提示

- 操作反馈（成功/失败）以右上角或顶部居中的轻提示（Toast，几秒后自动消失的提示条）出现。
- 二次确认、表单编辑等使用居中模态弹窗（遮罩背景、点击遮罩或按 ESC 通常可关闭；下载进行中等不可中断场景会禁用这三者，见第 12 章）。

### 错误边界

页面渲染发生异常时不会整应用白屏，而是显示降级页面：标题「程序出现异常」、具体错误信息，以及两个按钮——「重载应用」（主按钮，刷新整个应用）与「尝试恢复」。边界分三层：应用最外层的兜底层（降级页面替换整个三栏界面），与两个局部子树隔离层——拓扑画布挂载点（画布崩溃仅画布区降级，页面壳的按钮/弹窗继续可用）和 AI 助手页路由出口（AI 页崩溃仅内容区降级，侧栏与其他页面不受影响）。

### 表格通用行为

列表页的表格列宽不足时内容以省略号截断，悬停可见完整内容的提示气泡；长文本字段（备注、路径等）普遍如此处理。

## 页面路由

灵枢使用哈希路由（地址形如 `#/topology`、`#/devices`……，地址栏 # 号后的路径即当前页面）。八条页面路由（另有根路径 `/` 自动重定向到拓扑管理）：

| 路径 | 页面 |
| --- | --- |
| `/topology` | 拓扑管理（默认页，登录后首先进入） |
| `/devices` | 设备列表（设备管理分组子页；页题栏标题显示「设备管理」） |
| `/windows-hosts` | Windows 主机（设备管理分组子页，见 [第 5 章](./05-devices.md)） |
| `/ip-management` | IP 管理 |
| `/ai` | AI 助手 |
| `/knowledge-base` | 知识库 |
| `/logs` | 日志审计 |
| `/settings` | 系统设置 |

## 常见问题

**Q1：右侧那条竖把手是干什么的？**
详情栏的收起/调宽把手，仅在拓扑页单选一台设备或一条连线时出现。单击收起或展开，拖动调宽度；详情栏内容为对应的设备/连线详情（见第 4 章）。

**Q2：我在拓扑页摆好的画布，切到设备管理再回来变了？**
页面切换会重建画布组件，视图状态（缩放/平移位置）不保留；但节点位置、连线等拓扑数据已实时保存，回来时数据还在，只是视图复位。

**Q3：列表上方出现黄色「已显示前 N 条」提示是什么意思？**
单次查询结果超过了安全上限，只展示了前 N 条。按提示收紧筛选（如选择网段、时间范围）即可看到目标数据。

**Q4：删除类按钮为什么是红色的？**
红色是危险样式，标示删除等破坏性操作，提示谨慎点击。其中「从拓扑移除」「删除连线」等轻删免确认、可重做；彻底删除设备、删除拓扑等破坏性更大的操作则带二次确认（气泡或弹窗）。

**Q5：界面显示「程序出现异常」怎么办？**
先看影响范围：只画布区或 AI 页内容区降级时（局部错误边界），侧栏与其他页面仍可用，直接换页操作或稍后重进该页即可。整应用降级时先点「尝试恢复」重试（它会重新渲染界面）；无效则点「重载应用」。这是错误边界的降级页面，说明刚才的操作触发了渲染异常，重载后一般可继续使用；若稳定复现，记下 subTitle 中的错误信息反馈给维护者。
