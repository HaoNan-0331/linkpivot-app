# 第 10 章 系统设置

## 功能概述

系统设置是管理员主战场：AI 模型与多模态模型配置（含上下文窗口与最大输出 Token）、设备/Windows 双通道命令白名单与命令黑名单、执行模式与审批超时、Agent 任务硬顶、多步任务与巡检参数（任务最大轮数/巡检并发数）、上下文压缩阈值、LLM 报文记录开关、沙箱文档存储管理、账号安全（修改密码与恢复码管理）、AI 提示词注册表、AI 用量统计（token 消耗与费用、模型单价、明细保留期）、MCP 服务与包管理、以及关于页（版本与手动检查更新）。

#### 命令黑名单卡

黑名单内的命令首词在**任何执行模式与执行态下一律直接拒绝**，不进入确认流程。卡内说明原文：「黑名单命令任何档位直接拒绝；内置词删除后将失去兜底保护（全自动档可直接执行该词）。」两个分区（分隔线隔开，对应两套通道）：

| --- | --- | --- |

内置黑名单覆盖关机重启、删除覆写、进入配置模式等高危命令首词，作为安全兜底——但遵循「列表是运维的，产品只给默认值」原则，内置词可以删除（删除即失去该词的兜底，删除前会二次警示）。加载失败时同样停用编辑面 + 重试（与白名单卡同款防护）。

**黑白名单规则语义**：命令安全校验按命令首词判定——先做分隔符注入拦截（防 `show && rm` 类拼接绕过），再比对黑名单首词（命中即拒），再过设备级策略（见 [第 5 章](./05-devices.md) 命令策略），最后按全局词表与执行模式分派。示例：免确认词表填 `show` 即放行所有以 show 开头的命令；填 `show *` 反而放行不了任何命令——星号不是通配符，命令首词（如 `show`）永远严格相等不了带星号的字符串（如 `show *`），应直接填首词 `show`。词表内命令按执行模式决定直接执行（全自动/智能）或弹审批面板（每次确认）；词表外命令智能档需确认、全自动档直接执行；黑名单与含分隔符的命令任何情况直接拒绝（见 [第 7 章](./07-ai-assistant.md)）。

#### 上下文压缩卡

控制 AI 会话长对话的自动压缩触发线。一行控件：「上下文压缩阈值」数字框（0.01~1.0，步进 0.05，默认 0.8）+「保存」按钮；说明小字「调小可更早触发自动压缩（测试用），默认 0.8」。

阈值的含义是**占模型上下文窗口的比例**（0.8 = 会话 token 达窗口 80% 时触发预防性压缩；窗口大小即上方 AI 模型配置卡的「上下文窗口」）。保存即刻生效，同时联动 AI 助手页 token 状态栏的进度条刻度与 Agent 任务的上下文预算（见 [第 7 章](./07-ai-assistant.md)）。保存成功提示「压缩阈值已保存」。

#### LLM 报文记录卡

控制是否记录 AI 调用的完整请求与响应原文（排障取证用——出问题时能看到网关实际收到/返回的一字不差现场）。一行开关 + 说明小字，说明原文：「记录发送给大模型的完整请求与响应原文（本地加密存储，保留 30 天，用于排障取证）。关闭后新调用不再记录，已有记录不受影响」。

行为要点：

- **默认开启**（安装即记录语义）；
- **即改即存**：拨动开关立即保存（无需另点保存按钮），开启提示「已开启 LLM 报文记录」、关闭提示「已关闭 LLM 报文记录」；保存失败自动回滚为拨动前的状态并提示「保存失败：{原因}」；
- **关闭不是删除**：关闭仅停止记录新调用，已有报文仍在本地加密保留 30 天、到期自动清理；查看入口在日志审计页（见 [第 9 章](./09-log-audit.md)）。

#### 沙箱文档存储卡

管理 AI 生成文档（Word/Excel 报告快照与执行脚本）占用的本机沙箱目录。三行信息：

- **统计行**：总占用（B/KB/MB/GB 自适应）/ 会话数 / 文件数；
- **保留天数**：数字框 1~365（默认 7），修改后停顿半秒自动保存并提示「保留期已保存为 {N} 天」；超过保留期未活动的会话目录在下次启动时自动清理；
- **「立即清理」按钮**：弹出二次确认（列出将清理的会话数与预计释放空间，并说明「导出过的文档不受影响」；无可清理内容时改为仅更新保留期），确认后执行并提示实际结果（如「已清理 3 个会话，释放 12.5 MB」）。

清理只影响沙箱内的快照——已通过文档附件卡「导出」另存的文件是独立副本，不受任何影响（见 [第 7 章](./07-ai-assistant.md) 文档附件卡）。

提交按钮上方有前置披露行（原文）：「修改密码后将自动作废当前恢复码并重新颁发，需重新保存一次」。

**成功行为两步走**：

1. 弹出阻断式窗口「密码已修改」——正文「为保障账号安全，已同步作废旧恢复码并颁发新码，请重新保存」，窗内是与首次启动同款的恢复码展示（警告横幅 + 每 4 位一组连字符码块 + 复制按钮 + 「我已妥善保存恢复码…」勾选门；恢复码形态与展示规则见 [第 2 章](./02-install-login.md)）；点「完成」收口，提示「密码已修改」，表单清空、下方恢复码状态行同步刷新；
2. **会话保持**：修改密码不会登出、不刷新界面、无需重新登录——登录凭证在后台静默换新（旧凭证随改密即时作废，别处用旧凭证的会话不再有效）。

改密在单个事务内完成「口令更新 + 旧恢复码作废 + 新码颁发」三件事，要么都成功要么都不发生。

### 用量统计页签

统计所有 AI 调用的 token 消耗与费用。token 是 AI 服务计量文字量并据此计费的基本单位，一次调用的输入与输出分别计数。AI 对话、智能体任务、拓扑发现、经验总结、经验重排、知识库等每次 AI 调用都会自动记录一条用量明细，无需手动开启；记录失败不会影响 AI 功能本身。

#### 汇总四卡

| 卡片 | 内容 |
| --- | --- |
| 总 Token | 所选时间范围内输入与输出 token 合计，副行分别显示「输入 {X} · 输出 {Y}」 |
| 总金额 | 按模型单价折算的费用（¥，两位小数，仅计已配价模型）。存在未配价模型时下方黄字提示「{N} 个模型未配价，涉及 {P}% token，金额未计其消耗」 |
| 调用次数 | 所选时间范围内 AI 调用总次数 |
| 估算占比 | 按估算口径记录的调用次数占比（%）。估算指 AI 服务方（网关）未返回用量数据时，应用按请求字符数折算出的近似 token 数（鼠标悬停卡片可见提示「网关未返回用量，按字符数估算」） |

汇总四卡只随时间范围变化刷新，切换聚合维度不会重算汇总。

#### 工具栏（双分段选择器 + 三按钮）

- **时间五档**（默认「本月」）：今天 / 近7天 / 近30天 / 本月 / 自定义。选「自定义」出现起止日期选择器；切回任一快捷档会自动清空自定义日期（两档取值互不残留）
- **维度三维**（默认「按天」）：按天 / 按会话 / 按功能域
- 「单价设置」按钮：打开模型单价设置弹窗（见下）
- 「导出 CSV」按钮：导出当前时间范围的全部用量明细（见下）；所选范围无调用记录时按钮置灰
- 「刷新」按钮：重新拉取汇总与聚合表

#### 聚合表与行内明细下钻

聚合表首列随维度切换，其余五列固定（输入 tokens、输出 tokens、缓存命中、调用次数、金额）：

- **按天**：首列为日期，由近到远排序
- **按会话**：首列为会话标题，按总 token 从大到小排序；无会话归属的后台调用（如自动发现）聚合为「后台任务」组；会话已被删除的行标题后带灰字「已删除会话」标注，数值保留不清除
- **按功能域**：首列为调用场景中文名，固定顺序：对话 / 智能体 / 拓扑发现 / 经验总结 / 经验重排 / 知识库（「文档报告」为预留分类，有数据前不显示）

「缓存命中」指部分 AI 服务商对重复上下文按更低缓存价计费的命中部分。

点击行首展开图标加载该行明细子表（按需加载，每页 10 条可翻页；收起再展开不重复请求，切换维度或时间范围后重新加载）。明细子表列：时间、功能域、模型、输入 tokens、输出 tokens、缓存命中、金额。输入/输出数字旁的「估」角标表示该数值为估算值（悬停提示「网关未返回用量，按字符数估算」），输入与输出两个字段各自独立标注。

金额列三态显示：

- 已配价：显示折算金额 ¥{X.XX}
- 明细行未配价：灰字「未配置」（可点击，直接打开单价设置弹窗）——应用不会用估算值冒充金额
- 聚合行含未配价模型：金额后带「*」上标（悬停提示「包含未配价模型 token，金额仅计已配价部分」）

空态提示两种：所选时间范围无任何记录时显示「所选时间范围内暂无用量记录」（附提示：AI 对话、拓扑发现、经验总结等每次调用都会自动记录 token 消耗）；某行有调用次数但展开为空时显示「该行明细已按保留期自动清理」（聚合数据长期保留，见数据保留卡）。

#### 单价设置（模型价格）

点工具栏「单价设置」（或明细行灰字「未配置」）打开弹窗。单价按**每百万 token** 的人民币计价，每个模型一行三栏：

- 输入价（¥/百万）——必填
- 输出价（¥/百万）——必填
- 缓存命中价（¥/百万，可选）——留空时缓存部分按输入价计算（金额只高估不失真）

弹窗会自动列出可能需要配价的模型：当前 AI 配置的主模型与多模态模型、所选时间范围内出现过的模型、已配过价的模型，取并集。

规则：任一栏已填的行，输入价与输出价必须齐备（行内红字「请输入输入价」「请输入输出价」）；整行全部留空的模型不保存——保存为**整批替换**语义，留空即删除该模型的单价。点「保存单价」成功提示「单价已保存」，汇总卡与聚合表金额立即按新单价重算。

金额公式（每条调用）：金额 = [非缓存输入 token × 输入价 + 缓存命中 token × 缓存价（未填按输入价）+ 输出 token × 输出价] ÷ 1,000,000，保留两位小数；未配价模型不计入任何金额。

#### 数据保留卡

「明细保留天数」数字框（0~3650，默认 90，旁注「0=永不删除」），**失焦或回车才提交**（与 ARP 保留天数同款防护，防止输入瞬态值触发误删）。卡片固定警示：「缩短保留期将立即清理超期明细（不可恢复），聚合数据不受影响」。

用量数据采用「明细 + 聚合」双轨存储：逐次调用的明细按保留期自动清理；按天/功能域/模型/会话的聚合计数长期保留，汇总卡与聚合表口径不受清理影响。清理在应用启动时与每次查询汇总前自动执行。

#### CSV 导出

点「导出 CSV」导出**当前时间范围**的全部明细（不按当前维度过滤）：弹出保存对话框（默认文件名 token-usage-{日期}.csv），确认后流式分批写入，数据量大也不会卡住界面。列依次为：时间、功能域、模型、会话（无会话归属记为「后台任务」）、输入tokens、输出tokens、缓存命中、金额（未配价为空）、估算标记（空 / 输入 / 输出 / 输入+输出）。文件带 UTF-8 BOM，Excel 打开中文表头不乱码。成功提示「导出成功: {保存路径}」。

### MCP 服务页签

#### MCP 配置区

卡片「MCP 配置」右上「新建配置」主按钮。表格列出全部 MCP 连接器，操作列：「测试 | 工具 | 编辑 | 删除」（删除带确认「删除配置「{名称}」？将同时解除与 N 台设备的绑定。」）。列含绑定设备（悬停看全名单）、最近测试（成功时显示「成功 · N 个工具 · 相对时间」，相对时间如「3 分钟前」）、启用开关（关闭后该连接器不再向 AI 提供工具，配置与设备绑定保留，随时可重新开启）。

- 配置名称（占位「配置名称（如：设备运维 MCP）」）、类型三选一：本地程序 (stdio) / 网络服务 (http) / MCP 包（仅新建可选——编辑已有配置时「MCP 包」选项禁用，stdio 与 http 之间仍可来回切换，切换类型会清空另一类型的命令/地址与令牌字段）；

- stdio：命令（占位「如 npx 或完整程序路径」）与参数（逐个添加，输入后按回车确认，占位「如 -y、@modelcontextprotocol/server-everything」）；http：服务地址与令牌（已存令牌脱敏回显，留空不修改，可显式清除）；
- 设备级环境变量区（见下）；
- 表单内「测试连接」：即时用当前输入（含未保存明文）发起测试（新建 MCP 包类型时不显示该按钮——包配置需先落库才有启动入口）；行操作「测试」用已保存配置测试并落库结果。

**测试过程面板**：三阶段进度「正在启动程序… → 正在建立连接… → 正在获取工具清单…」（附已耗时秒数与「取消」按钮）；成功显示「连接成功 · 协议版本 {v} · 共 N 个工具」+ 工具表（名称/描述/只读标签），点工具行开抽屉看详情；失败显示「连接失败」+ 错误原因与错误码及建议「可检查命令/地址与凭证后重试」。

**工具管理抽屉**（行操作「工具」）：该连接器全部工具的策略表——名称、描述、只读标注（「只读」绿标签，名字经核验的显示「已验证只读」）、启用开关、免确认勾选。免确认可勾性由后台判定：只有被服务声明为只读（readOnlyHint）的工具才可勾；否则勾选框禁用并提示「该工具未被 MCP server 声明为只读（readOnlyHint），只能逐次确认」。勾选免确认提示「已设为免确认：{工具名} 将在「智能」档下直接执行（「每次确认」档仍会弹窗）」。

#### 设备环境凭证区

配置绑定设备的 MCP 环境变量（凭证类值经此注入，不进命令行参数）。该区位于新建/编辑配置弹窗内，「本地程序 (stdio)」与「MCP 包」两种类型提供；http 类型仅绑定设备、无环境变量：

- 「绑定设备」按钮：弹窗选择设备（占位「选择要绑定的设备」，一次添加一台），确认后为该设备添加变量组；
- 每台已绑定设备一张卡：变量行（变量名 + 值 + 删除），「＋添加变量」按钮；值为空时占位提示「留空将使用包默认 {默认值}」；包声明的必填项缺失时保存被拦（提示哪台设备缺哪个必填项）；凭证值只回显末 4 位，未修改不会重新保存；
- 包的变量说明（EnvKeyMetaList）：列出包声明的变量元数据，必填项带红「必填」标签，有默认值的附「默认 {值}」标签。

#### MCP 包区（平级卡片）

右上「导入」主按钮为唯一导入入口，打开四步导入向导（选择文件 → 校验结果 → 预览详情 → 确认登记）。导入 .mcpb 包文件时执行六向量安全校验（manifest 结构 / 入口类型白名单 / 路径逃逸防护 / 双扩展伪装 / manifest 与内容一致 / envMeta 键集一致，逐项 ✓/✗ 与失败原因人话展示），并登记 SHA-256 全树指纹（防内容被替换——重导同名包时新旧指纹并排对比，内容变化需确认覆盖）。向导第一步附「下载 .mcpb 格式说明」链接（导出包格式说明文件，成功提示「已导出到 {路径}」，用于按规范自制包）。包列表操作：「重测」（重新校验测试）「指纹」（查看全树 SHA-256 与逐文件哈希清单）「删除」（需输入包名原文确认，确认弹窗列出将级联删除的关联配置、解绑设备数与包文件目录）。覆盖确认弹窗并列展示新旧指纹与 env 键变化三清单（保留/新增/删除），确认后替换。

## 典型配置流程：从零启用 AI 能力

1. 设置 → 通用设置 → 「AI 模型配置」卡：选提供商、填 API Key、填 Base URL（用官方 API 或中转服务的完整根地址，均需填写）、填模型名称，「上下文窗口」与「最大输出 Token」保持默认即可，点「保存配置」。预期提示「AI 配置已保存」。
2. （可选）「多模态模型配置」卡：填支持图片输入的模型名（如 gpt-4o），其余留空复用主配置。预期保存后知识库图片识别生效。
3. 「设备命令白名单」卡：按你设备族的命令风格添加只读查看类命令首词（如 `show`、`display`、`ping`），点「保存」。预期提示「白名单已保存」。
4. 「执行模式」卡：日常建议保持「每次确认」；熟悉后可切「智能」；「全自动」需输管理员密码。
5. 到 [第 7 章](./07-ai-assistant.md) 验证：AI 页不再显示配置引导，可正常对话。

## 典型配置流程：接入一个 MCP 连接器

1. 设置 → MCP 服务 → 「新建配置」。预期弹出配置表单（stdio 类型附安全告警——逐字输入「我已知晓风险」确认工具来源可信）。
2. 选类型（本地程序 stdio / 网络服务 http），填名称与命令/地址；如需凭证在设备环境变量区「绑定设备」并添加变量（必填项缺失会在保存时被拦并指明缺哪个）。
3. 点表单内「测试连接」。预期看到三阶段进度，成功显示工具清单（名称/描述/只读标注）。
4. 保存配置（提示「配置已保存」；MCP 包类型新建为「配置已创建」），列表出现新行。
5. 点行操作「工具」打开工具管理抽屉：按需调整每个工具的启用与免确认（只读工具才可勾免确认）。预期勾选提示生效档位说明。
6. 到 AI 助手的设备选择器确认目标设备出现「可调MCP」蓝色标签。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| Key 脱敏保存 | API Key 以掩码回显；未改动的掩码串不会落库覆盖真实 Key（双层防护） |
| 全自动模式门槛 | 切换 auto 必须输入管理员密码；黑名单与越权命令在任何模式下仍拒绝/强制确认 |
| 改密作废重颁 | 修改密码在单个事务内完成口令更新、旧恢复码作废与新码颁发；改密后不登出（会话保持），旧登录凭证即时作废换新 |
| 恢复码重颁门槛 | 重新生成恢复码必须输入当前管理员密码（口令为空不发起请求）；旧码立即作废，新码仅显示一次 |
| 提示词门槛 | 编辑提示词需逐字输入「我已知晓风险」过门槛；门槛仅会话内有效 |
| 提示词冲突 | 官方升级与本地修改冲突时必须三选处理（保留我的/采用新默认/手动合并） |
| 占位符校验 | 提示词缺必需变量被实时提示 + 保存时网关层拦截 |
| 词表保存 | 标签墙编辑后必须点「保存」才生效；重复项不可加（大小写归一查重） |
| 词表匹配 | 按命令首词严格相等匹配（无通配符）；黑名单优先于一切；含分隔符直接拒绝 |
| 内置词主权 | 黑名单内置词可删（删除经二次警示确认，删后该词失去兜底）；删除后重新添加不再带「内置」标识 |
| 词表加载失败防护 | 白名单/黑名单加载失败时停用编辑面（避免空集假象下保存清空既有配置），提供重试 |
| 审批超时提交 | 失焦/回车才提交；1~60 分钟围栏（界面 + 后台双防线） |
| 硬顶双防线 | 界面钳制 + 后台硬校验；调参不影响确认与越权检测 |
| 多步任务围栏 | 任务最大轮数 1-10000 / 巡检并发数 1-16 双防线围栏；调参不改变安全行为（任务续行仍需手动「继续」，子代理只读白名单不变） |
| 上下文窗口围栏 | 必填，换算后 4096~10000000（最高 10M）整数 token，表单校验 + 主侧保存围栏双防线；保存即刻生效 |
| 压缩阈值联动 | 阈值保存即刻生效，联动自动压缩触发线、状态栏刻度与 Agent 上下文预算 |
| 保留天数提交 | ARP 保留天数（IP 管理页·采集任务工具栏）与用量明细保留天数均失焦/回车才提交（防瞬态值触发批量删除）；0=永不删除 |
| 沙箱清理 | 只清沙箱内快照，已导出的文档不受影响；保留期修改即时保存（防抖半秒） |
| LLM 报文非破坏 | 关闭「LLM 报文记录」仅停新记录，已有记录保留 30 天自然过期；开关即改即存、保存失败自动回滚 |
| MCP 凭证 | 环境变量加密存储；stdio 每次新建弹安全告警；http 令牌脱敏留空不改 |
| 包指纹 | .mcpb 导入六向量校验 + SHA-256 指纹；内容变化覆盖需确认 |
| 免确认资格 | 仅服务声明只读的工具可设免确认；「每次确认」档下仍弹窗 |
| 用量金额口径 | 金额仅累计已配价模型；未配价显示「未配置」/「*」，不用估算值冒充 |
| 用量明细双轨 | 明细可清、聚合长存；缩短保留期立即清理超期明细且不可恢复 |
| 单价保存语义 | 整批替换：整行留空的模型不保存（等同删除其单价） |

## 常见问题

**Q1：API Key 填了之后显示 ****，是没存上吗？**
存上了。已保存的 Key 以脱敏形式回显；只要你不改这个字段，保存其它配置不会覆盖真实 Key。

**Q2：白名单加了 `show *` 为什么 AI 还是不执行/弹确认？**
`show *` 本身不会命中：白名单按命令首词严格相等匹配，星号不是通配符，应直接填 `show`（即可放行所有 show 开头的命令）。若填的就是 `show` 仍弹确认，则是当前执行模式为「每次确认」——此档一律确认（含白名单命令）；切到「智能」或「全自动」后白名单命令才免确认。

**Q3：切「全自动」要求的管理员密码是什么？**
就是登录灵枢用的管理员账号密码（安全二次确认，防止误开全自动）。

**Q4：提示词门槛每次都要输「我已知晓风险」？**
每次启动应用后的首次编辑需要一次；同一会话内后续编辑不再要求。登出不会重置（登出不重载界面，门槛状态保留，重新登录后仍可直接编辑）；重启应用后才重置。

**Q5：官方升级后我的提示词改去哪了？**
你的版本仍在，对应条目出现冲突标记；打开后三选处理，diff 视图可「仅看变化」快速定位差异。

**Q6：MCP 工具勾不了「免确认」？**
该工具未被 MCP 服务声明为只读。只有只读工具可设免确认；写操作类工具任何情况下都要确认。

**Q7：想手动看看有没有新版本？**
设置 → 关于 → 「检查更新」。手动检查不受任何压制档位影响，最坏也会给出失败原因与手动下载链接。

**Q8：采集间隔改了立即生效吗？**
采集间隔是任务级参数（在 IP 管理页「采集任务」页签新建/编辑任务时设置，5~1440 分钟）——设置页已无全局间隔。保存任务后调度立即按新值对账，下一轮按「本轮开始时刻 + 新间隔」推算；正在运行的采集轮不受影响（见 [第 6 章](./06-ip-management.md)）。

**Q9：退出登录会断开已开的终端窗口吗？**
不会。退出登录（设置 → 账号安全 → 「退出登录」）回到登录页，已打开的 SSH/Telnet 终端窗口与远程会话保持；退出整个应用才会全部断开。

**Q10：IP 管理的采集数据和设备数据是同一个库吗？**
是。ARP 采集等 IP 管理数据与设备/拓扑数据同库存储，共用同一套备份与迁移机制（旧版设置页「IP 管理」页签及其「数据库管理」卡已随任务制采集重构移除，见本章「已迁出：IP 管理采集设置」）。

**Q11：提示词改坏了怎么恢复？**
编辑器里的「恢复默认」可一键回到官方默认（有二次确认）；冲突条目也可在三选里直接「采用新默认」。

**Q12：MCP 配置删了，绑定的设备环境变量怎么办？**
删除配置时提示会同时解除与 N 台设备的绑定；设备级变量随绑定一并清理，不会残留孤儿数据。

**Q13：用量统计里金额显示「未配置」或带「*」是什么意思？**
「未配置」出现在明细行：该条调用的模型没配单价，金额一栏不显示数字，也不会用估算值冒充；聚合行金额后的「*」表示该行含未配价模型的消耗，显示金额只计已配价部分。到「单价设置」为该模型补价后金额立即重算。

**Q14：为什么汇总数字还在，展开却提示明细已被清理？**
用量数据是「明细 + 聚合」双轨：聚合计数长期保留，逐次调用明细按「数据保留」卡设置的天数自动清理。想保留更久可调大天数（0=永不删除）；已清理的明细无法找回。

**Q15：黑名单里的「内置」词能删吗？**
能——内置词只是产品提供的默认兜底，删除时会弹警示（「删除后全自动档将直接执行该词，确认删除？」），确认即删。删除后该词失去黑名单兜底；重新添加同名词会作为普通追加词（不再带「内置」标识）。

**Q16：审批超时能关掉吗？**
不能关闭，只能调时长（1~60 分钟）。它是防止待确认命令无限挂起的兜底：超时未处理自动按拒绝收尾，AI 对话中会出现「审批超时已自动拒绝」系统提示。

**Q17：调小「上下文压缩阈值」有什么用？**
让长会话更早触发自动压缩（阈值是窗口占比，默认 0.8）。主要用于测试压缩行为，或所配模型窗口较小、想在更早水位收缩上下文的场景（窗口大小可在「AI 模型配置」卡的「上下文窗口」调整）。调得越小压缩越频繁、被摘要替代的近期消息越多，日常不建议低于默认值。

**Q18：沙箱文档存储「立即清理」会删掉我导出的报告吗？**
不会。清理只针对应用数据目录里的沙箱快照；通过文档附件卡「导出」另存到你指定位置的文件是独立副本，永远不受清理影响。

**Q19：设置页顶部黄色横幅提示「检测到 N 处加密数据无法解密」？**
启动自检发现部分历史加密数据用当前密钥解不开（常见于更换 Windows 账户或重装系统后）。按横幅指引从数据目录的 backups 文件夹恢复较近的备份，或重新录入相关数据；关闭横幅后同一数量不再重复提醒。

**Q20：在应用里能改管理员密码吗？**
能。设置 → 账号安全 → 修改密码：输当前密码 + 符合策略的新密码（不低于 10 位且同时包含字母和数字）。改密后无需重新登录（会话保持），但会自动作废旧恢复码并弹窗颁发新码——务必当场保存新码。

**Q21：「重新生成恢复码」为什么要输密码？**
防止他人趁你已登录、短暂离开电脑时偷偷换码。需输入当前管理员密码才能作废旧码、换发新码；新码仅显示一次（与首次启动同款展示），旧码立即作废。恢复码找回密码的用法见 [第 2 章](./02-install-login.md)。

**Q22：「LLM 报文记录」关掉会删掉已有记录吗？**
不会。关闭只是停止记录新调用；已有报文仍在本地加密保留 30 天（到期自动清理），期间可在日志审计页查看（见 [第 9 章](./09-log-audit.md)）。

| 内置词 | 黑名单中随版本提供、带蓝色「内置」标识的默认词，删除需二次警示确认 |
| 执行模式 | confirm/smart/auto 三档，控制执行态下命令与工具的确认粒度 |
| 审批超时 | 待确认命令超过时限未处理即自动拒绝的兜底（默认 10 分钟，可配 1~60） |
| 执行态 | 会话级 plan/exec 开关（见第 7 章），执行模式只在执行态下作用 |
| Agent 硬顶 | 自主任务的步数/熔断/冷却三类上限参数 |
| 熔断 | 同命令连续失败达阈值后停止重试的保护 |
| 冷却 | 失败后暂不重试的等待期 |
| 任务最大轮数 | 多步任务（goal）的 Round 预算缺省（默认 256，1-10000；人类消息不消耗预算） |
| 巡检并发数 | 批量巡检子代理并行执行的设备台数（默认 4，1-16；单台失败隔离不炸整批） |
| 上下文窗口 | 模型一次能读入的最大 token 容量（设置页可配 4096~10M；未配置时代码级缺省 128000） |
| 上下文压缩阈值 | 触发会话自动压缩的窗口占比（默认 0.8），联动状态栏刻度与 Agent 预算 |
| LLM 报文记录 | 记录发送给大模型的完整请求/响应原文的功能（本地加密存储、保留 30 天，排障取证用） |
| 沙箱文档存储 | AI 生成文档快照与执行脚本的本机存放目录，可查占用/设保留期/立即清理 |
| 账号安全 | 设置页页签：修改管理员密码与恢复码管理（状态查看/重新生成） |
| 会话保持 | 修改密码后不登出、不重登，登录凭证在后台静默换新的机制 |
| 加密自检 | 启动时校验历史加密数据可解性的检查，坏行以横幅提醒 |
| override | 对官方默认提示词的本地覆盖版本 |
| 占位符 | 提示词中的 `{{变量名}}` 模板变量 |
| 升级 diff 三选 | 冲突条目的保留我的/采用新默认/手动合并决策 |
| token | AI 服务计量文字量并据此计费的单位，输入与输出分别计数 |
| 估算 | 服务方未返回用量数据时按字符数折算的近似 token 数（「估」角标/估算占比） |
| 缓存命中 | 部分服务商对重复上下文按更低缓存价计费的命中部分 |
| 功能域 | 用量统计对 AI 调用场景的分类（对话/智能体/拓扑发现/经验总结/经验重排/知识库） |
| 明细/聚合双轨 | 逐次调用明细可按保留期清理，按天等聚合计数长期保留的存储方式 |
| 配价 | 为模型设置每百万 token 单价（输入/输出/缓存命中三价） |
| stdio | 以本地子进程方式运行的 MCP 连接器类型 |
| readOnlyHint | MCP 服务对工具只读性的自我声明，免确认资格依据 |
| 设备级环境变量 | 按设备注入 MCP 进程的环境变量（凭证通道） |
| .mcpb | MCP 包文件格式，导入时做六向量校验与指纹登记 |
| SHA-256 指纹 | 包内容哈希，用于检测替换与覆盖确认 |
| 保留策略 | ARP 数据自动清理天数（0=永不删除；入口在 IP 管理页「采集任务」页签工具栏） |
| 脱敏回显 | Key/令牌以掩码展示、未改动不覆盖真实值的保存机制 |
| 分诊 | 更新检查失败按网络/代理/限流等六类归类给出人话提示 |
| 发布页直链 | 关于页提供的 GitHub Releases 快捷入口 |
| 中转地址 | 兼容 OpenAI 风格的第三方 API 代理服务地址（Base URL） |
| 设备绑定 | MCP 连接器与其环境变量生效的设备范围 |
